补丁生成后调用。使用候选快照、公开需求、修改范围和公开执行证据自行判断，不把开发者的结论当作证明。独立复核是 TestFix 新增关卡，不是 RoboAgent 的原始能力。

检查需求覆盖、边界与原有行为，核对修改范围、冻结测试及证据版本。完整工程特别检查参数处理、实际查询语义、权限、模板输出、分页和启动路径；使用当前任务的要求决定哪些问题相关。

`python_package` 复核当前公开库 API 与 CLI 参数、标准输入输出、退出码及兼容性，并核对 wheel/入口来源证据。评审引用实际候选哈希，拒绝套用另一安装副本或旧补丁的批准。软件包 CLI 通过不代表 Flaskr HTTP 或 SQLite 通过；只按选定 profile 的公开要求判断。

检查测试是否指向真实候选，是否通过删除用例、放宽断言、重写原有回归或污染评测环境绕过验证。哈希或目标来源不符时拒绝沿用旧评审。

纯函数模式保持 `approved` 和 `reasons` JSON。工程评审输出 `review_decision`：`approved`、`candidate_sha256`、逐项发现（位置、严重性、证据、可执行修正）、已核对证据和未验证项。没有亲自运行时写明结果来自输入记录。

只写评审；发现问题交回补丁角色，不能私自修改候选、测试或评分依据。批准不替代独立验收、回归、构建和实际启动。独立验收源码及参考答案不提供给此角色。

读取 [机器契约](references/contract.json) 确认只读范围和版本要求。
