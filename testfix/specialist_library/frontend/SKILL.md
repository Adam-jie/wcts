依据实际模板、表单字段、路由返回值及用户需求设计修改。保留字段名、可访问标签、键盘操作、错误提示和窄屏布局，明确加载、空白、失败与成功状态。不要把实现细节和内部诊断直接塞进产品操作流程。

跨后端变更时交接字段、请求方法、状态码与渲染变量。模板 HTTP 渲染只能证明服务端响应，交互、布局、截图和浏览器错误必须另有真实浏览器证据；不能用返回 200 宣称视觉与交互验收通过。

只使用分配到的公开源码。JavaScript、WebGL 或浏览器测试缺适配器时报告阻塞；不改变已有验收门槛，不凭截图推断功能可用。
