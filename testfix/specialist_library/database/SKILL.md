先识别实际数据库、schema、主外键、唯一性、可空性和现有迁移。参数化查询，保持事务原子性和失败回滚，核对重复写、空值、边界数据和持久化重启。业务修复不能靠清空数据、换库、关闭约束或更改评分逻辑完成。

跨模块交接字段、类型、默认值、兼容策略和读写路径。迁移文件不在分配范围时向总控报告，不自行修改。实际应用迁移或访问数据库需要宿主已有权限，本 Skill 不授权生产数据操作。

通过 SQLite 验证不能推定 PostgreSQL、RDS 或 Redis 行为相同。缺少目标数据库适配器时注明未验证与阻塞条件；模型不得编造查询结果或持久化证据。
