核对项目实际 Three.js 版本，定位场景图、坐标、相机裁剪面、renderer 尺寸与像素比。保持交互拾取、旋转缩放、标签投影和拆解状态的一致性；事件与材质、纹理、geometry 必须按生命周期释放。用户要求代码生成模型时不引入外部模型文件。

建议验证所有可点击部件、拖拽和点击区分、缩放边界、复位、触屏、尺寸变化及 WebGL 不可用反馈。用实际浏览器观察动画和控制台异常；静态构建和模型自评不能证明画面正确。记录版本、浏览器与 GPU 环境。

没有 WebGL 浏览器适配器时实现任务阻塞。不得自行打开浏览器、下载资源或扩大文件范围。向页面 Agent 交接 DOM、尺寸和标签接口。
