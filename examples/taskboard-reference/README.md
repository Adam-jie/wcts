# TaskBoard：待修复的任务管理网页工程

这是为 TestFix 上传与补全流程编写的原创演示工程，包含 Python HTTP 后端、SQLite 数据库及暗色 HTML/CSS/JavaScript 前端。它是小型流程演示样例，不作为大型开源项目基准或比赛效果数据。

## 本地运行

安装 Python 3.11 或更高版本，不需要安装第三方依赖。在本目录执行：

```powershell
python -X utf8 server.py
```

打开 http://127.0.0.1:8878 。首次运行自动生成十条演示任务，数据位于 `var/tasks.sqlite3`。更换端口可执行 `python server.py --port 8879`；使用新数据库可指定 `--db var/another.sqlite3`。

## 已有功能

- 页面及静态资源正常加载。
- 创建任务、删除任务、读取单条任务、显示任务列表。
- 创建的数据持久化至 SQLite，重新打开数据库后保留。
- 空白标题被拒绝；接口使用 JSON 并返回相应 HTTP 状态码。

## 请修复的现象

1. 输入“中文搜索”进行搜索，仍显示其他不相关任务；不存在的关键词也不会显示空结果。
2. 点击“下一页”，内容与第一页重复。
3. 勾选一条任务为已完成，重新读取或刷新后完成状态丢失。

保留原有新增、删除及持久化行为，正确处理中文、空结果和分页边界，不允许通过删除用例、固定返回值或更改原始测试来制造通过。
