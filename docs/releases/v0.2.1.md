# v0.2.1 发布记录

本版本将当前软件工程工作台、桌面壳和可复现的软件样本统一发布。Windows 桌面版本为 0.1.6，安装、启动和验证命令见 [复现说明](../reproduce.md)。

## 本次调整

- 源码包包含前端、桌面端、构建页面和各自依赖锁。
- WCTP 七个核心源码经团队授权随包提供，启动时校验原始文件 SHA-256。发布内容中的 WCTP 部分只有核心源码与来源清单。
- 软件修复、功能补全和从启动骨架实现三个样本可以在新目录直接登记。
- 模型生成测试使用当前需求和正确的 WSGI 调用方式，补丁输出约束绑定当前源码版本。
- Windows 应用重启的短暂就绪读取错误按启动时限重试。
- 浏览器测试识别实际控件，首次及复用预览均记录候选版本。
- 测试 Skill 明确完整值匹配和列表成员匹配的含义，相关回归使用真实 HTTP 验证。
- 整轮实测在补全、WCTP 或浏览器阶段失败时返回非零退出状态。
- FEA-Bench 固定版本源码与微软原始许可证随包归档，来源清单记录上游 Git revision 和逐文件校验值。

## 本机桌面截图检查的限制

打包程序已构建，11 项桌面生命周期自动化检查通过。2026-11-07 的真实窗口检查观察到三维初始化完成，但 Electron 截图接口返回 `UnknownVizError`；默认与关闭 GPU 两种启动方式均未取得截图，随后检查超时。因截图位于恢复验证之前，本次没有取得完整的窗口恢复校验回执；不能用旧版成功截图替代本次结果。该限制独立于上面的网页端真实浏览器 8 步测试。
