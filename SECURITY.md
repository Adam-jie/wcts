# Security

This is a local research/development tool. Skill contracts, path checks and subprocess limits are not a general operating-system sandbox. Run only inspected repositories in the supported adapters and keep the local API bound to loopback.

Do not post secrets or private repositories in public issues. Describe suspected bugs with synthetic inputs and omit credentials, personal paths and raw model traces. Configure authentication only through local environment files or the selected provider's own login mechanism. No contact information or credential is distributed with this source release.
